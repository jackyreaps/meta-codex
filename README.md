# meta-codex

A Lean 4 metaprogramming library and formal framework for **structural realism in higher-dimensional abstractions**—auditing whether recursive towers, layered structures, and existential fibers carry genuine mathematical necessity rather than acting as passive type-level scaffolding.

> *"The solution is a topologically true artifact—a perfectly consistent construct generated by a higher dimensional differential argument—which simultaneously embodies a 'looks true' paradox."*

## Overview

In dependent type theory, kernel acceptance guarantees **local type inhabitance**, not **structural necessity**. Because proof irrelevance (\(P \land \text{True} \leftrightarrow P\)) and existential quantification (\(\exists L, \dots\)) allow deep recursive hierarchies to pass type-checking while forwarding vacuous witnesses or unidentifiable structural fibers, `meta-codex` pairs metaprogramming audits with formal underdetermination models:

1. **Transitive Cone & Vacuity Auditing (`#audit_theorem`):** Re-exports [`ScaffoldingAudit`](https://github.com) from `jackyreaps/X-files` to trace active dependency cones and flag definitions whose bodies peel to `True`.
2. **Structure Field Projection Auditing (`#audit_fields`):** Scans transitive proof terms for kernel projections (`Expr.proj`) and eliminators (`casesOn` / `rec`), distinguishing fields that are actually opened from passive payload carried across wrapper lemmas.
3. **Existential Fiber & Unidentifiability Analysis (`#audit_fibers`):** Detects `Type`-level existential witnesses whose structural parameters (`rank`, `dim`, topology) are projected out before reaching the headline conclusion.
4. **Inductive & Replay Integrity (`#audit_inductives`):** Verifies parameter and index metadata consistency across mutual and nested inductive blocks in the active cone.

## Quickstart

### 1. Add `meta-codex` to `lakefile.toml`

```toml
[[require]]
name = "meta-codex"
git = "https://github.com"
rev = "main"
```

### 2. Run Audits in Any Lean 4 File

```lean
import MetaCodex

#audit_theorem myHeadlineTheorem
#audit_fields myHeadlineTheorem MyLayeredStructure
#audit_fibers myHeadlineTheorem
#audit_inductives myHeadlineTheorem
```
